# 部署上线

本文档说明把服务部署到阿里云 ECS，并让网页和微信小程序同时上线。目标是一台最小规格的服务器跑一个 Go 进程，数据在一个 SQLite 文件里，每天自动备份。

## 总体结构

```text
                    ┌──────────────────── 阿里云 ECS（2 核 2G）────────────────────┐
浏览器 ──HTTPS──┐    │                                                             │
                ├──> │ Caddy :443 ──> harmony :8080（仅监听 127.0.0.1）             │
小程序 ──HTTPS──┘    │   自动证书        │ 内置 H5 静态文件                          │
                    │                  ├─> /var/lib/harmony/harmony.db（SQLite）  │
                    │                  ├─> /var/lib/harmony/uploads/（原图）       │
                    │                  └─> 百炼千问（仅识别）                      │
                    │ 每日 03:30 备份 ──> /var/backups/harmony ──> OSS              │
                    └─────────────────────────────────────────────────────────────┘
```

网页和小程序访问同一个域名：网页打开 `https://<域名>/`，小程序请求 `https://<域名>/api/v1/...`。两端没有各自的数据，所以不存在同步问题。

## 资源与费用

| 资源 | 规格 | 说明 |
| --- | --- | --- |
| ECS | 经济型 e 实例，2 vCPU、2 GiB，ESSD Entry 40 GiB，固定带宽 3 Mbps，包年 | 地域选华东（杭州或上海）；系统 Ubuntu 24.04 LTS，x86_64 |
| 域名 | 一个 `.com` 或 `.cn` | 在阿里云购买，方便与备案在同一账号下办理 |
| OSS | 标准存储，一个私有 Bucket，与 ECS 同地域 | 只存备份，几十 MB，费用几乎为零 |
| 百炼 | 按量计费 | 见 `06-识别接入千问.md` |

阿里云对新用户常有经济型 e 实例约 99 元一年的活动价，购买时以当时页面为准。必须包年购买并且剩余时长不少于 3 个月，否则无法用它办理 ICP 备案。

内存估算：Go 进程常驻 30 到 60 MB，Caddy 约 30 MB，SQLite 页缓存按默认值几 MB，2 GiB 有大量余量。1 GiB 规格也能跑，但系统更新、编译依赖时容易吃紧，不建议。

## 备案与审核

上线前有三件需要等待外部审核的事，越早开始越好。它们之间的依赖关系：

```text
买 ECS（包年）─┐
买域名 ─> 域名实名认证 ─┴─> ICP 备案（阿里云代提交，管局审核）─> 公安联网备案（上线后 30 天内）
                                                  │
小程序备案（微信公众平台，与上面并行）─────────────┤
                                                  ▼
                              小程序后台配置合法域名 ─> 体验版 ─> 提交审核 ─> 发布
```

| 事项 | 在哪办 | 时长 | 注意 |
| --- | --- | --- | --- |
| 域名实名认证 | 阿里云域名控制台 | 1 到 3 天 | 个人身份证 |
| ICP 备案 | 阿里云 ICP 代备案系统 | 1 到 3 周 | 个人备案；网站名称不能带"账本""金融""商城"这类可能被认为是经营性的词，建议用"某某的个人主页"一类名称；备案期间域名不能解析到这台服务器的 80/443 |
| 小程序备案 | 微信公众平台"设置 → 小程序备案" | 1 到 2 周 | 个人主体，需要人脸核验；服务内容类目要与后面提交审核的类目一致 |
| 公安联网备案 | 全国互联网安全管理服务平台 | 1 到 2 周 | 网站开通后 30 天内办理 |
| 小程序审核 | 微信公众平台 | 1 到 7 天 | 见"小程序发布" |

ICP 备案下来之前，服务器可以先部署好，通过 SSH 端口转发在本机浏览器里访问 `http://localhost:8080` 做验证，不需要等备案。

## 服务器初始化

以下命令以 root 身份执行一次。

### 安全组

| 方向 | 端口 | 来源 | 用途 |
| --- | --- | --- | --- |
| 入 | 22 | 你家和公司的出口 IP | SSH |
| 入 | 80 | 0.0.0.0/0 | 证书签发与跳转 HTTPS |
| 入 | 443 | 0.0.0.0/0 | 网页与接口 |

8080 不开放：后端只监听 `127.0.0.1`，只能经过 Caddy 访问。

### 系统

```bash
apt update && apt upgrade -y
apt install -y caddy sqlite3 unattended-upgrades
timedatectl set-timezone Asia/Shanghai

# SSH 只允许密钥登录
sed -i 's/^#\?PasswordAuthentication .*/PasswordAuthentication no/' /etc/ssh/sshd_config
systemctl restart ssh

# 运行账号与目录
useradd --system --home /var/lib/harmony --shell /usr/sbin/nologin harmony
install -d -o harmony -g harmony -m 0750 /var/lib/harmony /var/lib/harmony/uploads /var/backups/harmony
install -d -m 0755 /opt/harmony /etc/harmony

# journald 日志上限
mkdir -p /etc/systemd/journald.conf.d
printf '[Journal]\nSystemMaxUse=500M\n' > /etc/systemd/journald.conf.d/size.conf
systemctl restart systemd-journald
```

Ubuntu 24.04 官方源里的 Caddy 版本足够新；如果不是，按 Caddy 官网的说明添加它的 apt 源。`sqlite3` 只用于人工排查和恢复演练，服务本身不依赖它。

### 目录约定

| 路径 | 内容 | 权限 |
| --- | --- | --- |
| `/opt/harmony/harmony` | 当前版本二进制 | root 0755 |
| `/opt/harmony/harmony.prev` | 上一个版本，用于回滚 | root 0755 |
| `/etc/harmony/config.yaml` | 配置，不含机密 | root 0644 |
| `/etc/harmony/harmony.env` | 机密环境变量 | root 0600 |
| `/var/lib/harmony/harmony.db` | 数据库，连同 `-wal`、`-shm` | harmony 0640 |
| `/var/lib/harmony/uploads/` | 识别原图 | harmony 0750 |
| `/var/backups/harmony/` | 本地备份，保留 7 天 | harmony 0750 |

## 配置

### config.yaml

```yaml
server:
  host: "127.0.0.1"
  port: 8080
  mode: "release"

database:
  path: "/var/lib/harmony/harmony.db"

storage:
  uploadDir: "/var/lib/harmony/uploads"

recognize:
  provider: "qwen"
  baseURL: "https://dashscope.aliyuncs.com/compatible-mode/v1"
  model: "qwen-vl-max"
  timeoutSeconds: 90
  temperature: 0
  highResolution: true
  dailyLimit: 100

auth:
  adminUserIds: [1]
  mpTokenDays: 30
  webTokenDays: 14

wechat:
  appID: "wx348e5ad03f9cd6ba"
  envVersion: "trial"

backup:
  dir: "/var/backups/harmony"
  keepDays: 7
```

`server.host` 是新增配置项（现在 `main.go` 监听的是 `:port`，即所有网卡），默认值 `127.0.0.1`。`backup` 是新增配置段，供 `harmony backup` 子命令使用。

### harmony.env

```bash
HARMONY_RECOGNIZE_API_KEY=sk-...
HARMONY_WECHAT_APP_SECRET=...
HARMONY_AUTH_SECRET=...        # openssl rand -base64 48 生成
TZ=Asia/Shanghai
```

文件权限 0600，属主 root；systemd 以 root 读取后注入进程，`harmony` 账号自己读不到这个文件。

### systemd

`/etc/systemd/system/harmony.service`：

```ini
[Unit]
Description=harmony ledger
After=network-online.target
Wants=network-online.target

[Service]
User=harmony
Group=harmony
EnvironmentFile=/etc/harmony/harmony.env
ExecStart=/opt/harmony/harmony -config /etc/harmony/config.yaml
Restart=on-failure
RestartSec=3
WorkingDirectory=/var/lib/harmony
NoNewPrivileges=true
ProtectSystem=strict
ProtectHome=true
PrivateTmp=true
ReadWritePaths=/var/lib/harmony /var/backups/harmony
LimitNOFILE=4096

[Install]
WantedBy=multi-user.target
```

`ProtectSystem=strict` 让整个文件系统对进程只读，只有 `ReadWritePaths` 列出的两个目录可写，进程即使出问题也写不到别处。

### Caddy

`/etc/caddy/Caddyfile`，把 `ledger.example.com` 换成备案后的域名：

```text
ledger.example.com {
	encode zstd gzip
	request_body {
		max_size 8MB
	}
	header {
		Strict-Transport-Security "max-age=31536000"
		X-Content-Type-Options "nosniff"
		Referrer-Policy "same-origin"
		-Server
	}
	reverse_proxy 127.0.0.1:8080
}
```

Caddy 自动向 Let's Encrypt 申请和续期证书，不需要手动上传。前提是 ICP 备案已经通过、域名已解析到这台服务器，否则 80 端口被拦截，证书申请会失败。

`request_body` 设为 8MB：识别上传限制 5MB，留出 multipart 开销。

## 构建与发布

### 本机构建

根目录 `Makefile` 新增 `release-linux` 目标：

```bash
make release-linux
# 1. cd frontend && pnpm install && pnpm build:h5
# 2. 复制 H5 产物到 backend/web/dist
# 3. cd backend && GOOS=linux GOARCH=amd64 CGO_ENABLED=0 \
#      go build -trimpath -ldflags "-s -w -X main.version=$(git describe --tags --always)" \
#      -o bin/harmony-linux-amd64 ./cmd/harmony
```

切换到纯 Go 的 SQLite 驱动之后（见 `05-SQLite存储.md`），在 Mac 上就能直接产出 Linux 二进制，服务器上不需要安装 Go 和 Node。

### 首次部署

```bash
scp backend/bin/harmony-linux-amd64 root@<服务器>:/opt/harmony/harmony
ssh root@<服务器>
sudo -u harmony /opt/harmony/harmony migrate -config /etc/harmony/config.yaml
systemctl daemon-reload && systemctl enable --now harmony
curl -s http://127.0.0.1:8080/api/v1/health
systemctl reload caddy
```

### 日常发布

新增 `deploy/deploy.sh`，由 `make deploy HOST=<服务器>` 调用，依次执行：

1. 上传新二进制到 `/opt/harmony/harmony.new`。
1. 执行 `harmony backup`，发布前先备份一次。
1. 用新二进制执行 `harmony migrate`。快照全部是 `IF NOT EXISTS`，只会补建新表和新索引。
1. `harmony` → `harmony.prev`，`harmony.new` → `harmony`，`systemctl restart harmony`。
1. 每秒请求一次健康检查，10 秒内不返回 200 就自动回滚：`harmony.prev` 换回 `harmony` 并重启，脚本以非零退出。

改动已有表的字段（例如加列）不能靠快照完成。这种发布要在 `backend/migrate/sqlite/` 下附带一个一次性的 `YYYYMMDD-说明.sql`，在第 3 步之后人工执行，执行前已经有第 2 步的备份兜底。

### 回滚

```bash
ssh root@<服务器> 'cd /opt/harmony && mv harmony harmony.bad && mv harmony.prev harmony && systemctl restart harmony'
```

如果新版本已经写坏了数据，按"恢复"一节用发布前的备份还原。

## 备份与恢复

### 每日备份

`harmony backup` 子命令做三件事：

1. `VACUUM INTO '/var/backups/harmony/harmony-20261108-0330.db'`：在线生成一个完整的数据库副本，不停服务。
1. 删除 `auth_token` 中过期超过 7 天的行（顺带清理）。
1. 删除本地超过 `keepDays` 天的备份文件。

上传到 OSS 由脚本 `deploy/backup.sh` 完成，systemd timer 每天 03:30 执行：

```bash
#!/usr/bin/env bash
set -euo pipefail
/opt/harmony/harmony backup -config /etc/harmony/config.yaml
latest=$(ls -t /var/backups/harmony/harmony-*.db | head -n 1)
gzip -kf "$latest"
ossutil cp -f "$latest.gz" "oss://<bucket>/db/$(basename "$latest").gz"
ossutil sync /var/lib/harmony/uploads "oss://<bucket>/uploads/" --update
rm -f "$latest.gz"
```

- `ossutil` 使用一个只有该 Bucket 写权限的 RAM 子账号 AccessKey，配置在 root 的 `~/.ossutilconfig` 中，权限 0600。
- Bucket 设置生命周期规则：`db/` 前缀 90 天后删除；`uploads/` 不删除。
- Bucket 为私有，不开公共读。

另外在 ECS 控制台为系统盘设置自动快照策略：每周一次，保留 4 份。快照用于整机故障时快速重建，OSS 备份用于数据级恢复，两者互补。

### 恢复

```bash
systemctl stop harmony
cd /var/lib/harmony
mv harmony.db harmony.db.broken; rm -f harmony.db-wal harmony.db-shm
ossutil cp oss://<bucket>/db/harmony-20261108-0330.db.gz . && gunzip harmony-20261108-0330.db.gz
mv harmony-20261108-0330.db harmony.db && chown harmony:harmony harmony.db
sqlite3 harmony.db 'PRAGMA integrity_check;'   # 期望输出 ok
systemctl start harmony
```

上线后第一周做一次恢复演练：在本机用 OSS 上的备份按上面步骤恢复，启动后核对记录条数与线上一致。

## 监控

| 项 | 方式 | 告警 |
| --- | --- | --- |
| 服务存活 | 阿里云云监控"站点监控"，每 5 分钟 GET `https://<域名>/api/v1/health` | 连续 2 次失败发短信 |
| 主机 | 云监控默认指标：CPU、内存、磁盘 | 磁盘使用超过 80% 发短信 |
| 备份 | `backup.sh` 失败时 systemd 单元失败；`OnFailure=` 触发一个发邮件的单元 | 邮件 |
| 识别费用 | 百炼控制台设置月度费用预警 | 超过 20 元短信 |
| 日志 | `journalctl -u harmony -f` | 不告警，排查时看 |

`release` 模式下日志级别为 info，访问日志不记录请求体；姓名、金额只在 debug 级别出现（`02-后端设计.md` 日志一节）。

## 小程序发布

### 构建配置

新增 `frontend/.env.production`（入库，不含机密）：

```bash
VITE_MP_API_BASE=https://ledger.example.com/api/v1
```

`frontend/src/manifest.json` 中 `mp-weixin.appid` 填 `wx348e5ad03f9cd6ba`，`setting.urlCheck` 改为 `true`。

仓库根目录和 `frontend/` 下现在有微信开发者工具生成的 `project.config.json`、`project.private.config.json`，它们未提交。处理方式：`frontend/project.config.json` 是 uni-app 构建时会覆盖的产物，加入 `.gitignore`；根目录那两个是误在根目录打开开发者工具生成的，删除。

### 后台配置

微信公众平台"开发管理 → 开发设置 → 服务器域名"：

| 类型 | 值 |
| --- | --- |
| request 合法域名 | `https://ledger.example.com` |
| downloadFile 合法域名 | `https://ledger.example.com`（导出文件下载） |

uploadFile 不需要配置：小程序不上传图片。

"设置 → 服务内容声明 → 用户隐私保护指引"：

- 收集的信息：微信 OpenID，用于区分不同用户的账本。
- 用户主动录入的信息：亲友姓名、电话、往来金额，仅用于用户本人记账，存放在开发者自有服务器，不向第三方提供。
- 不收集位置、相册、通讯录、手机号。

### 发布步骤

1. `pnpm build:mp-weixin`（生产模式），`make release-mp` 检查产物里没有识别代码。
1. 微信开发者工具导入 `frontend/dist/build/mp-weixin`，上传为开发版，在公众平台设为体验版。
1. 服务器 `wechat.envVersion` 设为 `trial`，重启服务。
1. 用你自己的微信打开体验版，完成一次登录，认领管理员（见 `07-登录与鉴权.md`）。确认"我的"页面显示管理员身份。
1. 在电脑浏览器打开网页，扫码登录，确认网页首页有识别入口。
1. 按 `fen.md` 9.3 节在真机上走一遍验收。
1. 提交审核。类目在提交页的列表中选择"工具"下最贴近记账的二级类目；如果个人主体可选列表里没有，选"工具 → 效率"。审核备注写明"个人记账工具，登录后即可使用，无需测试账号"。
1. 审核通过后发布，服务器 `wechat.envVersion` 改为 `release`，重启服务。

## 上线检查清单

1. ECS 包年购买，安全组只开放 22（限 IP）、80、443。
1. 域名实名认证、ICP 备案通过，解析到 ECS 公网 IP。
1. 小程序备案通过。
1. `harmony.env` 中三个机密都已设置，权限 0600。
1. `harmony migrate` 执行成功，健康检查返回 `database: sqlite`、`journalMode: wal`。
1. Caddy 证书签发成功，`https://<域名>/` 能打开网页，HTTP 自动跳转 HTTPS。
1. 直接访问 `http://<公网IP>:8080` 不通。
1. 管理员已认领；第二个微信号登录看到空账本。
1. 手动执行一次 `backup.sh`，OSS 上能看到数据库和原图。
1. 云监控站点监控、百炼费用预警已配置。
1. 网页底部显示 ICP 备案号并链接到 `https://beian.miit.gov.cn`；公安联网备案在 30 天内完成后，把公安备案号也加上。
